# Aviation Analysis Dashboard

## Project Overview
Developed an interactive Aviation Analysis Dashboard in Microsoft Excel to analyze aircraft accidents, damages, operational phases, yearly trends, and KPIs.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Dashboard

## Features
- Accident trend analysis
- Damage severity analysis
- Operational phase analysis
- Interactive dashboard visualization

## Outcome
Generated actionable insights from aviation datasets through data cleaning, visualization, and trend analysis.
